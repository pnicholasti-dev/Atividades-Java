# Atividades-Java
Atividades para curso de especialização em Java

1 – Sistema de
Empréstimos


Criei uma classe chamada Emprestimo
com os atributos valor do empréstimo, quantidade de parcelas e taxa
de juros. Desenvolvi um construtor para inicializar os atributos,
implementei os métodos get e set e criei um método chamado calcularValorFinal(),
responsável por calcular o valor total do empréstimo considerando a taxa de
juros. Sobrescrevi o método toString() para exibir todas as informações
do empréstimo. Na main, criei um objeto, calculei o valor final e apresentei o
resultado.

2- Sistema Bancário


Desenvolvi uma classe Conta
contendo os atributos número da conta, titular e saldo. Em
seguida, criei duas subclasses: ContaCorrente, que possui o atributo limite,
e ContaPoupanca, que possui o atributo rendimento. Utilizei
herança, construtores com super, implementei os métodos get e set
e sobrescrevi o método toString() em cada subclasse. Na main, criei uma
conta corrente e uma conta poupança, alterei alguns dados utilizando setters e
exibi as informações completas de cada objeto.

3- Sistema de
Financiamento de Veículos


Desenvolvi uma classe Financiamento
contendo os atributos nome do cliente, valor do veículo, entrada
e quantidade de parcelas. Depois, criei uma classe FinanciamentoVeiculo
que herda Financiamento e acrescentei o atributo taxa de juros
anual. Utilizei herança, construtores com super, implementei os métodos get
e set e desenvolvi um método calcularValorFinanciado(), que
calcula o valor total a ser pago considerando a entrada e a taxa de juros.
Sobrescrevi o método toString() para apresentar todas as informações do
financiamento. Na main, criei um financiamento, calculei o valor total e exibi os
dados do cliente e do contrato.
